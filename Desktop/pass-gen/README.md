# 🔐 Advanced Password Generator\n\nA modern, responsive password generator web application with an enhanced UI and advanced features.\n\n## ✨ Features\n\n- **Modern UI Design** - Beautiful gradient background with smooth animations\n- **Customizable Generation** - Choose password length (4-32 characters)\n- **Character Options** - Select from uppercase, lowercase, numbers, and symbols\n- **Strength Indicator** - Visual strength meter with detailed analysis (0-100 scale)\n- **One-Click Copy** - Copy passwords to clipboard with confirmation\n- **Password History** - Keep track of recently generated passwords (last 5)\n- **LocalStorage Support** - History persists across browser sessions\n- **Responsive Design** - Works perfectly on desktop, tablet, and mobile\n- **Toast Notifications** - User-friendly feedback messages\n\n## 🚀 How to Run\n\n### Option 1: Using Node.js (Recommended)\n\n```bash\nnode server.js\n```\n\nThen open your browser and navigate to: `http://localhost:3000`\n\n### Option 2: Using Python\n\n#### Python 3:\n```bash\npython -m http.server 3000\n```\n\n#### Python 2:\n```bash\npython -m SimpleHTTPServer 3000\n```\n\nThen open your browser and navigate to: `http://localhost:3000`\n\n### Option 3: Using Live Server (VS Code Extension)\n\n1. Install \"Live Server\" extension in VS Code\n2. Right-click on `index.html`\n3. Select \"Open with Live Server\"\n\n## 📋 File Structure\n\n```\npass-gen/\n├── index.html      # Main HTML structure\n├── style.css       # Enhanced styling and animations\n├── script.js       # Core functionality and features\n├── server.js       # Node.js HTTP server\n└── README.md       # This file\n```\n\n## 🎨 UI Components\n\n- **Password Display** - Large, easy-to-read password field with copy button\n- **Length Slider** - Interactive slider to set password length (4-32)\n- **Character Options** - 4 checkbox options for customization\n- **Strength Meter** - Color-coded strength indicator (red → yellow → green → blue)\n- **Generate Button** - Large, prominent button to create new password\n- **History Section** - Displays last 5 generated passwords\n\n## 🔒 Strength Levels\n\n- **Weak** 🔴 (< 30/100) - Short password, limited character variety\n- **Fair** 🟡 (30-60/100) - Decent password, decent variety\n- **Good** 🟢 (60-80/100) - Strong password with good variety\n- **Strong** 🔵 (80-100/100) - Very strong, excellent variety\n\n## 🛠️ Browser Support\n\n- Chrome/Edge (latest)\n- Firefox (latest)\n- Safari (latest)\n- Mobile browsers (iOS Safari, Chrome Mobile)\n\n## 📦 Dependencies\n\n- None! This project uses only vanilla HTML, CSS, and JavaScript\n- Works completely offline once loaded\n\n## 🎯 Tips\n\n- **Symbols** checkbox includes: `!@#$%^&*()_+-=[]{}|;:,.<>?`\n- Passwords are generated client-side - nothing is sent to any server\n- History is stored in browser's localStorage\n- Clear history using the \"Clear History\" button\n\n## 📝 License\n\nFree to use and modify!\n
